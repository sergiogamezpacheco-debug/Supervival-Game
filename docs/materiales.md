# Materiales

Nombres como en el diseño "Materiales y recursos". Los iconos salen de `tools/iconos/items2.py`.

| Objeto | De dónde sale | Dónde se usa |
|---|---|---|
| Troncos (`madera`) | Pinos | Casi todo |
| Piedra bruta (`piedra`) | Rocas | Cantería, herramientas |
| Mena de hierro (`mineral_hierro`) | Veta de hierro | Horno → lingote de hierro |
| Chatarra | Montones, infectados, cajas | Horno, banco nv2 (componentes) |
| Tablones, bloque de piedra | Carpintería y cantería | Construcción |
| Lingote de hierro | Horno | Herramientas, metal |
| Mena de cobre (`mineral_cobre`) | Veta de cobre (cantera) | Horno → lingote de cobre |
| Lingote de cobre | Horno (3 mena + 2 troncos) | Cables y piezas finas (próximamente) |
| Tela | Infectados, cofres | Costura |
| Cuero curtido (`cuero`) | Mesa de costura: 2 pieles + 1 fibra | Mochilas y equipo (próximamente) |
| Azufre | Veta de azufre (cantera) | Pólvora |
| Pólvora | Banco de trabajo nv2: 2 carbón + 1 azufre → 2 | Munición y explosivos (próximamente) |
| Componentes | Banco nv2: 4 chatarra; botín de blindado, coloso y cajas | Armas, generador, recicladora |

La recicladora (siguiente paso) sacará más componentes de la chatarra que el banco.
